# 🎵 Streamzy

> **A modern, fast, and immersive music streaming experience.**

Streamzy is a modern music streaming application built with a premium glassmorphism interface and a powerful audio playback system. It is designed to make discovering, playing, and managing music simple, smooth, and enjoyable.

- Play / Pause controls

- Shuffle mode

- Fast song loading and buffering

## 🎵 Music Player

Streamzy includes a full-featured music player with:

- Album artwork
- Song title
- Artist information
- Play / Pause
- Previous / Next
- Seek bar
- Current playback time
- Total duration
- Shuffle
- Repeat
- Queue
- Background playback
- Lock-screen controls

The mini-player allows users to control currently playing music without leaving the current screen.

---

## 🔍 YouTube Music Search

Streamzy integrates music discovery through the YouTube Data API.

Users can:

- Search for songs
- Find artists and music
- Browse search results
- View thumbnails
- View song titles
- View artist/channel information
- Open selected results through the supported YouTube player

API requests are optimized using debouncing, caching, and pagination.
